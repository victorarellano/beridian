# Project Roadmap

## Purpose

This roadmap describes the evolution of the Beridian project from business analysis to a production-ready financial platform.

Each phase defines:

- Product goals
- Engineering goals
- Learning goals
- Deliverables
- Exit criteria
- Success indicators

---

## Current Status

Beridian is currently in **Phase 03 — Financial Period Experience**.

The domain analysis and backend MVP have been completed. Current development focuses on building the end-to-end financial period experience, integrating the implemented business rules, application use cases, persistence, and API operations into a complete financial workflow.

For detailed goals, deliverables, and completion criteria, see [Phase 03 — Financial Period Experience](./03-financial-period-experience.md).
