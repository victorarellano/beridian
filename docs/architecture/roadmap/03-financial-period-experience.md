# Phase 3 — Financial Period Experience

## Purpose

Transform the backend capabilities into an intuitive user experience centered around the Financial Period.

The objective of this phase is not simply to build a web interface, but to provide users with a clear and efficient way to plan, monitor, and complete an entire financial period.

The user should interact with financial periods rather than isolated transactions.

---

## Product Goals

At the end of this phase, users should be able to:

- Create and open financial periods.
- Visualize the current financial period.
- Register planned and actual financial information.
- Navigate between financial periods.
- Track the progress of the current period.
- Identify pending financial concepts.
- Close a financial period through the user interface.

The application should provide a complete workflow that replaces the current spreadsheet-based process.

---

## Engineering Goals

Build a modern, maintainable web application.

During this phase the project should:

- Design the presentation layer.
- Implement reusable UI components.
- Consume the backend API.
- Manage application state.
- Implement client-side validation.
- Handle authentication (if applicable).
- Apply responsive design principles.
- Establish a scalable frontend architecture.

## Exit Criteria

This phase is complete when:

- Users can perform every core business operation through the graphical interface.
- The application no longer requires direct interaction with the API.
- The complete monthly workflow can be executed using only the web application.
- Financial periods can be managed from creation to closure.
- The interface clearly represents the business concepts defined in the domain model.

---

## Success Indicators

The application successfully replaces the existing spreadsheet workflow.

A user can:

- Create a new financial period.
- Plan expenses and incomes.
- Record actual financial information.
- Monitor financial progress.
- Close the financial period.
- Generate the next period.

The user understands the current financial situation without needing to inspect raw financial records.
